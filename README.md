# Location → CD

Hands-free lookup for the CD sheet: type or say a location number, get its CD.

- **Voice in** — tap the mic, say “six oh four” (also “MA six zero four”, “double four”).
- **Voice out** — the answer is spoken: “M A six zero four. C D four four.”
- **Keep listening** — stays open, reads each number as you say it, keeps the screen awake.
- **Voice commands** — “repeat”, “clear”, “stop”, “listen”.
- **Keypad** — glove-friendly big buttons.
- **Recent** — last lookups, tap to replay.
- **Installable / offline** — add to home screen; the table works with no signal (voice needs data).

`index.html` carries the full table inline (343 rows transcribed from the printed sheet).

Sheet anomalies kept as printed, not “corrected”:

- MA605 is not printed — the column runs MA604 → MA606 (70).
- MA700 and MA701 both print 12.
- MA599 = 07 and MA600 = 89 break the +13 run the rest of the sheet follows.

Covered ranges: MA001–020, MA500–659, MA700–863.
